## 📅 Roadmap & Daily Breakdown

### 🔹 Day 1–2: Python Basics & Environment
- Basic syntax and script execution.
- Variables, dynamic typing, and primitive data types (integers, floats, strings, booleans).
- Console input and formatted output.
- *Files:* `Day 1-2/Day_1.py`, `Day 1-2/Day_2.py`

### 🔹 Day 3: Operators, Expressions & Arithmetic Logic
- Arithmetic operators (`+`, `-`, `*`, `/`, `//`, `%`, `**`).
- Comparison operators (`==`, `!=`, `<`, `>`, `<=`, `>=`).
- Boolean logic (`and`, `or`, `not`) and operator precedence.
- Mini problem-solving challenges and review exercises.
- *Files:* `Day 3/arithmetic.py`, `Day 3/comparision.py`, `Day 3/logical.py`, `Day 3/challenge.py`, `Day 3/project.py`

### 🔹 Day 4: Conditionals & Control Flow
- Single-condition decision making with `if`.
- Two-way branching with `if-else`.
- Multi-tier decision logic with nested conditional blocks.
- Practical validation exercises and decision problems.
- *Files:* `Day 4/if.py`, `Day 4/ifelse.py`, `Day 4/nested.py`, `Day 4/challenge.py`, `Day 4/program.py`, `Day 4/projects.py`

### 🔹 Day 5: Multi-Way Branching & Practical Problem Solving
- Decision ladders using `elif`.
- Finding the largest among multiple numbers (`largest.py`).
- Leap year calculation algorithm (`leap_year.py`).
- Tiered electricity billing calculation (`electricity.py`).
- Basic login credential verification flow (`login.py`).
- *Files:* `Day 5/elif.py`, `Day 5/largest.py`, `Day 5/leap_year.py`, `Day 5/electricity.py`, `Day 5/login.py`, `Day 5/challenge.py`

### 🔹 Day 6: Console Applications & Mini-Projects
- **ATM Simulator (`Day 6/atm.py`):** Interactive menu handling PIN verification, balance inquiry, cash withdrawal, and deposit.
- **Calculator (`Day 6/calculator.py`):** Multi-operation arithmetic calculator with user input selection.
- **Admission Eligibility Checker (`Day 6/admission.py`):** Validating student qualification based on composite academic marks.
- **Movie Ticket Pricing (`Day 6/movie.py`):** Age-based tiered admission pricing.
- **Student Exam Results (`Day 6/result.py`):** Calculating total marks, percentages, and assigning academic letter grades.
